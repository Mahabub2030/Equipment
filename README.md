# Equipment Management System

This project is a web-based application designed to manage and display landscaping equipment details. The system provides a user-friendly interface to search, view, and manage equipment information, including stock availability and condition.

## Features

- **Search Functionality**: Easily search for equipment using the search bar.
- **Equipment Display**: Cards display equipment images, names, and stock status.
- **Modal for Details**: View detailed information about equipment conditions via modals.
- **Responsive Design**: Optimized for different screen sizes using Tailwind CSS and DaisyUI.

## Technologies Used

- **HTML**: Markup structure for the web page.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **DaisyUI**: Tailwind CSS component library for UI elements.
- **JavaScript**: For dynamic functionalities like search and modals.
- **Font Awesome**: Icon library for visual enhancements.

## Installation

1. Clone the repository:
    ```bash
    git clone <repository-url>
    ```

2. Navigate to the project directory:
    ```bash
    cd equipment-management-system
    ```

3. Open `index.html` in your preferred browser.

## Usage

1. Open the web page.
2. Use the search bar to find specific equipment.
3. Click on the "Condition" button to view detailed information about the equipment.
4. Close the modal by clicking the "Close" button.
